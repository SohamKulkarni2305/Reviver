Title: Introduction to Machine Learning

Machine learning is a subset of artificial intelligence that enables computers to learn from data without being explicitly programmed. It was first described by Arthur Samuel in 1959.

Key methods include supervised learning, unsupervised learning, and reinforcement learning. Supervised learning uses labeled training data to make predictions. Unsupervised learning finds patterns in unlabeled data. Reinforcement learning trains agents through reward and penalty signals.

Common applications include image recognition, natural language processing, recommendation systems, and fraud detection. The field has grown rapidly since the introduction of deep neural networks in the 2010s.
